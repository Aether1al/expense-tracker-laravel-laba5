# Трекер личных расходов (Expense Tracker)

Веб-приложение на Laravel для учета личных финансов, фильтрации трат по категориям и месяцам, а также контроля бюджета.

## Обработанные краевые случаи

* **Изоляция данных пользователей:** каждый пользователь видит, редактирует и удаляет только свои траты. При попытке обратиться к чужой записи по прямому URL возвращается ошибка `404 Not Found`.
* **Валидация даты:** запрещено добавлять и сохранять траты с датой в будущем (`before_or_equal:today`).
* **Валидация суммы:** запрещен ввод отрицательных значений и нуля (`numeric|min:0.01`).
* **Проверка категории:** невозможно сохранить трату с несуществующим `category_id` (`exists:categories,id`).
* **Пустой список и фильтрация:** корректное отображение таблицы при отсутствии записей и сохранение параметров фильтра при переключении страниц пагинации.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone ВАША_ССЫЛКА_НА_РЕПОЗИТОРИЙ
   cd имя-папки
   ```
2. Установите зависимости и настройте окружение:
   ```bash
   composer install
   cp .env.example .env
   php artisan key:generate
   ```
3. Настройте подключение к БД в файле `.env` и выполните миграции:
   ```bash
   php artisan migrate --seed
   ```
4. Запустите локальный сервер:
   ```bash
   php artisan serve
   ```

## Запуск тестов
